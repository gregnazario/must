One config. Every language.

A polyglot build orchestrator with first-class support for Rust, Go, C/C++, TypeScript, Python, Zig, Docker, and Lua plugins.

$ cargo install --path crates/must-cli

Why must?

Consistent Verbs

must build, must test, must outdated — same commands for every language. No more remembering whether it's npm run or cargo run.

20 Recipe Types

First-class support for Rust, Go, C/C++, TypeScript, Python, Zig, Docker, shell, and extensible Lua plugins. Each type knows how to build, cache, and cross-compile.

Smart Caching

Content-hash caching for compiled recipes, mtime for shell. Branch-switch safe. must outdated shows what's stale at a glance.

Cross-Compilation

Automatic GOOS/GOARCH for Go, cross-rs containers for Rust, C cross-compilers. Define targets once, build everywhere.

Lua Plugins

Extend must with .lua scripts. Shell exec, file I/O, glob, env access — all built in. Drop a file in .mustfile/plugins/ and go.

Build Logs

must log <recipe> shows the last build output. --follow streams in real time. --clear wipes old logs.

See it in action

Mustfile.toml

[project]
name = "myapp"

[recipe.build]
type    = "rust-bin"
package = "myapp"

[recipe.test]
type    = "rust-test"
package = "myapp"
deps    = ["build"]

[recipe.lint]
type   = "shell"
phony  = true
script = "cargo clippy -- -D warnings"

Polyglot project

[recipe.api]
type    = "go-bin"
package = "./cmd/api"

[recipe.frontend]
type    = "ts-bin"
package = "web"

[recipe.image]
type    = "docker-build"
image   = "${REGISTRY}/api:latest"
deps    = ["api"]

Commands

must build [recipes] Build one or more recipes
must test [recipes] Run test recipes
must explain <recipe> Show cache key, inputs, env, command preview
must outdated Show cache status for all recipes
must list List all recipes with types and deps
must graph Visualize the dependency graph
must log <recipe> Show last build output
must log --follow Stream logs in real time
must plugin list List and validate plugins
must plugin check Validate a single plugin
must watch Watch files and rebuild on change
must doctor Check toolchains and environment

Extend with Lua

Plugin (.mustfile/plugins/protoc.lua)

function execute(ctx)
    local protos = glob("proto/*.proto")
    for _, p in ipairs(protos) do
        shell_exec("protoc --rust_out=src " .. p)
    end
    return {
        stdout = "generated " .. #protos .. " files",
        stderr = "",
        success = true,
    }
end

Config (Mustfile.toml)

[recipe.codegen]
type   = "plugin"
plugin = "protoc"
